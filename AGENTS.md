# Standing Rules
- RULE ZERO: one scoped change per commit
- Never run git commands — Human handles all git ops manually
- Two-attempt limit per task
- Show diff and wait for explicit go-ahead before applying any change
- Never run two changes concurrently on same file
- No sudo
- Before any fix changing function behavior: paste real caller code first
- Q6_K panel kernel permanently off-limits (14x regression documented)
- do NOT touch .git directory
- After any .h file change, run `make clean && make` (stale object files can hide struct layout mismatches)
